# Changelog

## v1.2.0

### Workspace redesign

- Browse a compact folder tree, pin files to Favourites, and reopen documents from Recent. Tabs show file types and provide an overflow menu on smaller screens.
- Resize or hide navigation. The docked inspector brings together the outline, backlinks, tags, linked documents, tasks, and local history.
- Switch between Live, Source, Split, and Preview. Live renders Mermaid diagrams, fenced code, and tables while keeping their Markdown editable.
- Search notes in the knowledge graph, group task lists by status, and browse settings by category.

### Builds

- Version tags build Windows x64 and Apple silicon desktop installers.
- Version tags publish a Docker image for Linux amd64 and arm64 to GitHub Container Registry.
